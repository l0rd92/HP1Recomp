# HP1Recomp v0.1.0-alpha

This is the first native Windows alpha prepared from the canonical USA
`SLUS-01415` build.

## Validated behavior

- Boot, language selection, title menu and new-game flow.
- Warner and EA presentation with the transient post-Warner corruption fixed.
- Vertical screen adjustment without the former alternating-frame flicker.
- A 49.5-minute new-game route through story scenes, lessons, combat and
  repeated indoor/outdoor loading transitions.
- Memory-card creation and a separate save, process restart and reload cycle.
- Keyboard, D-pad and left-stick input through the PSX digital-pad mapping.

## Known limitations

- A complete start-to-credits playthrough has not been performed. Later story
  and level boundaries are not yet claimed compatible.
- Left-stick movement is digital and can feel more sensitive than the D-pad.
- One spell-learning prompt was observed with controls near or beyond the
  visible edge; a later prompt rendered normally.
- Earlier tests intermittently suggested slower EA playback. The latest
  extended run was functional, but timing has not yet been classified.

## Original game required

This package does not contain the Harry Potter game, a retail PlayStation BIOS,
save data or copyrighted game assets. Supply your own legally obtained copy of
Harry Potter and the Sorcerer's Stone (USA, En/Fr/Es), serial `SLUS-01415`.
